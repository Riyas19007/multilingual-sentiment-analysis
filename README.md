# 🌍 Transformer-Based Multilingual Sentiment Analysis

## Overview
This project is a Transformer-Based Multilingual Sentiment Analysis System developed using Python and MySQL. It analyzes text in multiple languages and predicts whether the sentiment is Positive, Negative, or Neutral.

## Features
- 🌐 Multilingual text support
- 😊 Sentiment classification
- 🐍 Python implementation
- 🗄️ MySQL database integration
- 🤖 Transformer-based NLP model

## Technologies Used
- Python
- MySQL
- Transformers
- NLP
- Git & GitHub
